# Fraud Detection System using Machine Learning

## Overview
This project predicts fraudulent financial transactions using machine learning techniques.

## Features
- Fraud prediction
- Transaction analysis
- Streamlit web app
- Data preprocessing
- Machine learning classification

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- NumPy

## Models Used
- Logistic Regression
- Random Forest

## Project Outcome
The model predicts whether a transaction is fraudulent or safe based on transaction details and balance patterns.
